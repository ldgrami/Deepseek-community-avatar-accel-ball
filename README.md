# DeepSeek社区虚拟形象加速球

一个Windows 桌面悬浮球，用大肥鱼表情包当皮肤。基于 Python + PySide6 (Qt6) 开发，支持内存监控、一键加速、关闭程序、贴边隐藏、尺寸调节等功能。

## 功能特性

- **内存监控**：实时读取物理内存占用率，球体用 GIF 展示当前状态。
- **一键加速**：调用 Windows `EmptyWorkingSet` 释放各进程工作集，加速后播放"工作"动画若干秒。
- **程序管理**：点击球弹出面板，列出当前正在运行的程序（带图标、按内存占用排序），勾选后点"一键加速"即可结束这些程序。
- **贴边隐藏**：把球拖到屏幕边缘松手会吸附并缩成一条小竖条，鼠标移上去自动伸出，移开再缩回。
- **悬停气泡**：鼠标放到球上会随机播放一个表情，并在球上方用对话气泡显示"内存占用 XX%"。
- **尺寸调节**：面板内滑条可在 90–220px 之间自由调整球的大小。
- **动画时长**：面板内滑条可设加速后"工作"动画时长（1–30 秒，默认 5 秒）。
- **系统托盘**：托盘图标跟随当前动画，单击托盘也能打开面板。
- **开机自启**：右键菜单可开关（写入注册表 `HKCU\...\Run`）。
- **设置持久化**：尺寸、置顶、贴边、动画时长保存在 `config.json`。
- **单实例**：命名互斥量，避免重复启动。

## 运行方式

需要先安装 Python 3（当前使用 3.14）并安装依赖：

```
pip install -r requirements.txt
```

然后二选一：

- 双击 `run.bat`（用 `pythonw` 启动，无黑色控制台窗口）
- 命令行：`python accel_ball.py`

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 打开 / 关闭程序管理面板 |
| 左键拖动 | 移动小球位置 |
| 拖到屏幕边缘 | 贴边吸附并隐藏 |
| 鼠标悬停 | 随机表情 + 内存占用气泡 |
| 右键单击 | 菜单（打开面板 / 仅释放内存 / 窗口置顶 / 贴边隐藏 / 开机自启 / 退出） |
| 单击托盘图标 | 打开程序管理面板 |
| 按 Esc | 退出程序 |

## 程序管理面板

- 列出所有有可见窗口的用户程序，显示程序图标、名字和内存占用。
- 勾选要关闭的程序，点"一键加速 (N)"，确认后会强制结束这些进程，并顺带释放一次内存。
- 底部"球体大小""动画时长"两个滑条即时生效并自动保存。

## 配置

设置保存在同目录的 `config.json`（首次修改设置时自动生成）：

```json
{
  "size": 150,
  "topmost": true,
  "edge_hide": true,
  "anim_seconds": 5
}
```

- `size`：球体直径（90–220 像素）
- `topmost`：是否窗口置顶
- `edge_hide`：是否贴边隐藏
- `anim_seconds`：加速后工作动画时长（秒）

## 依赖

- Python 3
- PySide6（Qt6 界面）
- psutil（内存与进程信息）

均为第三方库，Windows 系统 API 通过内置 `ctypes` 调用（`EmptyWorkingSet` 释放内存、`EnumWindows` 枚举窗口）。

## 注意事项

- 仅支持 Windows。
- 结束程序属于危险操作，面板中点击"一键加速"会先弹确认框；未保存的数据可能丢失。
- 关闭系统级 / 受保护进程需要管理员权限，普通权限下会自动跳过。
- 如需清理或更换表情，直接替换 `assets/` 里的同名 GIF 即可。
